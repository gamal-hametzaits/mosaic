# 🧩 מוזאיקה - פסיפס העולם (Mosaic)

קנבס ענק משותף לכל העולם: 10,000×10,000 פיקסלים (100 מיליון משבצות).
כל משתמש מניח **פיקסל אחד קבוע ביום** (מתאפס בחצות UTC). אי אפשר להזיז, למחוק או לשנות פיקסל אחרי ההנחה. לאט לאט נבנית תמונה שהיא ההיסטוריה של המשתמשים.

**אתר חי:** https://mosaic.gamal-hametzaits.workers.dev

## מה יש ב-V1

- קנבס 100M פיקסלים עם זום חלק: עולם → אזור → פיקסלים בודדים (עם רשת)
- פיקסל אחד ביום למשתמש, אכיפה כפולה בשרת (אינדקס ייחודי + בדיקה)
- קביעות מלאה: אין ממשק עריכה/מחיקה לאף אחד. חריג יחיד: הסרת תוכן בלתי חוקי על ידי מנהל (נשאר תיעוד עם `removed_at`)
- היסטוריה מלאה לכל פיקסל: מי יצר, תאריך ושעה (טבלת `pixels`)
- התחברות עם גוגל (Sign in with Google, אימות ID token מול המפתחות הציבוריים של גוגל)
- פרופיל משתמש: רשימת הפיקסלים שלו + מיני־מפה של הפיזור שלו
- חיפוש: לפי שם משתמש, מספר פיקסל (`#123`), או קואורדינטות (`250,800`)
- סטטיסטיקה חיה: סה״כ פיקסלים, יוצרים, פיקסלים שהונחו היום, אחוז כיסוי
- פיד חי של הפיקסלים האחרונים
- מכונת זמן: סליידר שמציג את הקנבס כפי שהיה בכל נקודת זמן
- פרימיום (בסיס בלבד): 8 צבעי פרימיום נעולים בפלטה; אין תשלום ב-V1. הליבה חינמית לגמרי, אין pay-to-win

## ארכיטקטורה

- **Cloudflare Workers** - השרת והאתר (סטטי דרך Workers Assets)
- **Cloudflare D1** (SQLite) - משתמשים, פיקסלים (ההיסטוריה), אריחי ביטמאפ של הקנבס (tiles בני 250×250, בייט לכל פיקסל = אינדקס צבע), ותמונת overview של 1000×1000
- הכל בחשבון Cloudflare של הבעלים, תוכנית חינמית

### מבנה

```
worker/
  src/worker.js      - כל ה-API + לוגיקת הקנבס
  public/            - האתר (index.html, styles.css, app.js)
  schema.sql         - סכמת D1 (רצה אוטומטית בכל deploy, idempotent)
  wrangler.toml      - קונפיגורציה (מזהה D1, Google Client ID)
.github/workflows/deploy.yml  - deploy אוטומטי ל-Cloudflare בכל push ל-main
```

### Deploy מחדש

כל push ל-`main` שנוגע ב-`worker/**` מריץ deploy דרך GitHub Actions.
נדרשים סודות בריפו (Settings → Secrets → Actions):

- `CLOUDFLARE_API_TOKEN` - טוקן API של Cloudflare עם הרשאות Workers Scripts + D1
- `SESSION_SECRET` - מחרוזת אקראית ארוכה לחתימת סשנים

## גבולות התוכנית החינמית (נכון להקמה)

- Workers: ~100,000 בקשות ביום (מעבר לזה = שגיאות זמניות עד איפוס, לא חסימה)
- D1: 5 מיליון קריאות/יום, 100,000 כתיבות/יום, 500MB אחסון. הקנבס המלא בתצורת אריחים ~100MB, כלומר יש מקום
- קצב הנחות טבעי מוגבל (פיקסל אחד ביום למשתמש), כך שהמכסות רחוקות מהקצה

## מה נשאר ל-V2

- אירועי עולם (world events) על הקנבס
- תשלום/מנוי לפרימיום + הפעלת צבעי הפרימיום בפועל
- WebSocket לעדכון חי בלי polling
- אימות אפליקציית גוגל (להסרת מסך האזהרה "unverified app" בהתחברות)
